Infrastructure

Every cloud value the farm runs on, live since 2026-11-08 and checked. How the app uses them is in architecture.md. The plan for all three apps in the shared project is uma-rpg's cloud plan.

The shared project

uma-farm lives in GCP project uma-rpg (number 727687479415, billing account 0101E5-D99B49-A8B713), beside uma-rpg and uma-quest, all live. Each app has its own pieces, and none can reach another's. Four things are shared: - Firebase Auth: Google sign-in and the one allowed email; - the github-actions Workload Identity pool; - the $5 budget alert (emails at $1 and $5); - read-only access to uma-platform's gs://uma-platform-master-data.

Never change the active gcloud account. Scope every command:

CLOUDSDK_ACTIVE_CONFIG_NAME=default CLOUDSDK_CORE_PROJECT=uma-rpg gcloud run services describe farm-api --region=us-central1

Never run gcloud config set …, and never touch uma-rpg's or uma-quest's pieces: (default), quest, rpg-*, quest-*, github-deployer, quest-deploy, gs://uma-rpg-content, gs://uma-quest-content, and the uma-rpg and uma-quest sites.

Re-run and rollback

  • Re-run: CLOUDSDK_ACTIVE_CONFIG_NAME=default bash infra/bootstrap.sh describes each piece before creating it and re-applies the grants as they are, then prints the repository variables. It changes nothing on a second run: it pauses farm-push-tick only when it creates it, and a job that exists keeps its state.
  • Rollback, in this order:
    1. delete the scheduler job and the provider;
    2. unbind farm-api-runtime from gs://uma-farm-content, and delete the bucket with its versions (gcloud storage rm -r --all-versions gs://uma-farm-content);
    3. delete the service, the deployer, the two accounts and the secret.

The database keeps its delete protection, so removing it is a separate, deliberate step.

What it costs

The farm's share of the bill is the farm database and its recovery, a few cents a month: Google's free Firestore quota covers only (default). Everything else stays inside the free tiers it shares with uma-rpg and uma-quest: - the site, farm-api and the images; - the push tick, the second of three free scheduler jobs; - farm-vapid, the second of six free secret versions; - gs://uma-farm-content: about 3 MB a version, under 50 MB with history, and a few hundred reads a month, so $0.

Production saves

These rules come from uma-rpg's 2026-10-30 incident, where a hand grant wiped unsynced progress: - never move save.account.updatedAt; - no server ever writes into a save; - a stale server date means stop and ask the owner.

Parcels, when they come, keep to them: they live in parcels, never inside a save, and each game records its claims in its own save.
