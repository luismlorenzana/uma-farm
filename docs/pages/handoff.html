Across the repos

  • uma-platform holds the shared pieces: master data, uma-kit, uma-work, uma-server, uma-art, and the HD-2D stage @luismlorenzana/uma-stage, which the farm no longer uses (its portrait preview retired with landscape). Shared changes go there as requests (change protocol).
    • uma-kit's landscape pieces: the farm asked for its layout on a landscape stage (a thin top bar, a left rail, the Account page and the place map). Until they ship, the farm draws its own bar and rail from the kit's pieces.
  • The art split: ChatGPT draws character art (Uma sprites, poses, busts, portraits). Claude draws everything else in code (items, UI marks, buildings, the HD-2D kits) in a uma-platform session.
  • uma-quest shares the story's way of working (the Uma Ranker's cast, tags and ties), read as local files on the owner's PC.
  • uma-rpg is frozen. The farm's v2 save engine was copied from it, never imported.
  • Parcels to uma-quest, uma-rpg and uma-racer are parked until the farm's own game is done. uma-quest's accept list is in its spec at a88838b (its clean slate removed it from main).

How a packet reads

A packet is one piece of work, written from the roadmap when it starts: - Why, and what to read first; - Decided: the calls already made, so the worker doesn't re-decide them; - Do: the steps; - Done when: the checks, including the owner's phone look when there is one; - Deliver: the branch, the pull request, the game mechanics updated for any rule change, and the packet deleted.
